# Демонстрационные данные

`seed_demo.py` заменяет все бизнес-данные: поставщиков, товары, остатки,
закупки, прямые продажи и клиентские заказы. Схему и историю Alembic не меняет.
Фотографии не добавляются. Цены условные, контакты вымышленные.

Набор содержит 36 товаров с описаниями и ценами, 6 поставщиков, 8 закупок,
3 прямые продажи и 12 заказов во всех шести статусах. Овощи и фрукты продаются
целыми упаковками. Есть низкие и нулевые остатки.

Каждый остаток объясняется принятыми закупками минус продажами и переданными
курьеру заказами. Резерв равен количеству в заказах `new`, `picking`, `ready`.
Весь набор заменяется в одной транзакции; записи на время замены блокируются.
При повторном запуске данные заменяются, идентификаторы продолжают расти.

Перед запуском сохраните резервную копию (из корня проекта):

```sh
mkdir -p backups
docker compose exec -T postgres sh -c 'exec pg_dump -U "$POSTGRES_USER" -d "$POSTGRES_DB" -Fc' > backups/before-demo.dump
```

Используйте новое имя файла для каждой копии, чтобы не перезаписать старую.
Каталог `backups/` исключён из Git.

После пересборки образа API скрипт доступен в контейнере:

```sh
docker compose exec -T api uv run --no-sync python -m scripts.seed_demo --replace-data --dry-run
docker compose exec -T api uv run --no-sync python -m scripts.seed_demo --replace-data
```

При локальном запуске из `app`:

```sh
uv run python -m scripts.seed_demo --replace-data --dry-run
uv run python -m scripts.seed_demo --replace-data
```

`--dry-run` проверяет данные и откатывает транзакцию; PostgreSQL при этом может
израсходовать значения последовательностей ID. `--replace-data` обязателен,
чтобы случайный запуск не удалил существующие данные.

Не запускайте старый `seed_stock.py` поверх этого набора: он выставляет случайные
резервы без привязки к клиентским заказам. Старый `seed.py` использует отсутствующий
эндпоинт приёмки и не подходит для актуальной версии API.

Для восстановления копии сначала остановите API, затем восстановите базу:

```sh
docker compose stop api
docker compose exec -T postgres sh -c 'exec pg_restore --clean --if-exists --single-transaction -U "$POSTGRES_USER" -d "$POSTGRES_DB"' < backups/before-demo.dump
docker compose start api
```

Восстановление заменяет текущее содержимое базы данными из копии.
